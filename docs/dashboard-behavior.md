# Dashboard 规则与插件编辑

保存规则或导入起源规则时，Dashboard 会提交读取规则时取得的 `revision`。后台规则发生变化时，保存返回冲突，编辑草稿保留。打开的规则按 `rule_id` 定位；同一规则被修改或删除后，需要重新打开并合并修改。接口字段见 [API 后端架构](api-backend-architecture.md)。

草稿恢复不保存敏感值。恢复已有节点时使用规则文件中的已保存值；新建或复制节点的敏感参数需要重新输入。恢复确认框会说明这一区别。规则文件中的敏感值没有加密，见 [变量与数据类型](data-types.md)。

JSON 参数输入在内容有效时写回规则，同时保留当前输入格式。数据类型在当前编辑器中切换后再切回，会恢复之前选择的时间单位和类型结构。

首次配置中的开机启动设置需要桌面桥。连接尚未就绪时，页面显示错误和重新读取按钮；应从 NotmyFault 桌面窗口完成配置。

插件页面加载完成或发送 `ready` 消息后接收一次 `init` 消息；同一页面的重复 `ready` 不再重复初始化。两个参数编辑入口均将空字符串作为 `null` 交给插件命令。消息和会话格式见 [插件扩展 API](plugin-extension-api.md)。

插件安装前，需要逐项确认安全预览中 `installation.required_risk_ids` 列出的风险。构建钩子的确认文字会明确说明执行插件自带命令。插件索引地址必须使用 HTTPS，见 [插件索引](plugin-registry.md)。

安全页的配置摘要隐藏参数值。重新签名前，应打开本机 `rules.json` 核对实际参数；摘要只用于查看规则和动作结构。

日志读取失败时显示独立错误，复制按钮只复制当前筛选结果并显示条数。运行记录导出包含当前已载入并筛选的全部记录；不会额外截成前 500 条。导出字段的脱敏规则见 [运行摘要策略](run-summary-policy.md)。

修改 AI 服务地址后，后台会清除为旧地址保存的密钥，Dashboard 会提示为新地址重新保存密钥。
